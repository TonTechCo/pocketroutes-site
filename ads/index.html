Manage Pocket Routes centrally.

Ad controls are now managed in TonTech AppAdmin alongside the other TonTech apps.

Open AppAdmin

Ads control → Pocket Routes

Set the NUVIAD percentage independently for between-delivery interstitials and optional hint ads. The remainder goes to AdMob. Turning off NUVIAD routes both placements to AdMob.

Publish in AppAdmin to update the game's configuration. GitHub Pages remains the delivery endpoint; the app refreshes on launch, resume and every five minutes. Deployment and caching may add time.

NUVIAD hint ads use interstitial inventory. Hints require five seconds of foreground viewing followed by dismissal. NUVIAD RTB requests require no API key. Precise GPS collection stays disabled.

The installed game must include remote routing. TestFlight build 10 predates this feature; the newer integration must ship in an app update before it can follow these settings.
